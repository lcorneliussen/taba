## Status

- **Open PRs are refreshed before old terminal ones.** Never-observed and active
  PRs are read first; merged, declined, closed and superseded PRs are rechecked only after
  them, so a refresh deadline no longer leaves new drafts unobserved. A PR that
  gets no turn keeps its last observed state, marked deferred.
  ([#535](https://github.com/lcorneliussen/taba/issues/535),
  [#541](https://github.com/lcorneliussen/taba/pull/541)).
