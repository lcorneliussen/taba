## Releases

- **Release candidates are published as GitHub prereleases.** A `v<version>-rc.N` tag no longer becomes the latest release, so `upgrade` without `--version`, mise's `latest` and the Homebrew formula stay on the stable release. Install a candidate with `upgrade --version <version>-rc.N` ([#202](https://github.com/lcorneliussen/wtc-cli/issues/202)).
