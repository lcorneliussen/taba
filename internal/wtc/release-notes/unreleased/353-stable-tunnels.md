## Services

- **Manage named tunnels and retain stable registrations.** Receiving-local project defaults and collection overrides share one CLI/UI lifecycle, explicit exposure approval, scoped provider inputs, events, active host/origin publication and interruption-safe owned cleanup. Managed manifests fence older clients before runtime teardown; older pre-retirement hooks can still run, and unresolved cleanup blocks retirement. Dev Tunnel hosting requires an existing Node22+ runtime.
  ([#353](https://github.com/lcorneliussen/taba/issues/353), [#394](https://github.com/lcorneliussen/taba/pull/394)).
