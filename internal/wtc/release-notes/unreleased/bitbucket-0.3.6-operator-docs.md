## OpenClaw

- **Bitbucket operator guidance follows the published 0.3.6 plugin.** Install
  that independent plugin separately, connect personal accounts through
  **Bitbucket** in the Control UI sidebar after signing in to OpenClaw, and
  use `--no-enable` when upgrading to preserve enablement, allowlists and
  denylists. Reload only an enabled installation; intentionally disabled
  installations stay disabled. Existing personal logins and settings are
  reused, and OpenClaw 2026.10.2 remains the minimum supported host.
