# taba/wtc 0.2.12-rc.1

Release candidate for testing status freshness across collections. Try it locally
with the [version guide](https://taba.sh/docs/versions/#try-the-latest-published-rc-in-one-collection).

## Status

- **Fewer routine forge reads.** Status uses the repository open-PR list, shares
  one request budget per forge, and records terminal outcomes to avoid repeated
  reads. Manual refresh checks the pane’s lists and can look up a PR missing
  from a capped list. [#563](https://github.com/lcorneliussen/taba/pull/563),
  [#564](https://github.com/lcorneliussen/taba/pull/564),
  [#566](https://github.com/lcorneliussen/taba/pull/566)
- **Keep observations during deferred refreshes.** Previously observed rows
  stay visible with their original age. A retained row does not grant actions.
  GitHub CLI keychain logins can share cached observations by configuration
  directory, host, and account. Replacing a keychain token for the same account
  can reuse that account’s observations. [#565](https://github.com/lcorneliussen/taba/pull/565),
  [#567](https://github.com/lcorneliussen/taba/pull/567)

- Status checks an existing cache directory without repeatedly trying to create it.
  [#571](https://github.com/lcorneliussen/taba/pull/571)

## Collections and services

- `taba svc --json` includes declared task tags.
  [#558](https://github.com/lcorneliussen/taba/pull/558)
- Project configuration can define `[mise.settings]` for generated collection
  environments. [#559](https://github.com/lcorneliussen/taba/pull/559)
