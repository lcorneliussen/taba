# taba/wtc 0.2.9

A stabilization release. Bitbucket works without `bb`, public reviews run in an
isolated context, a repository's root `dekit.yaml` declares its services, and
retries no longer repeat side effects. `taba prompts` shows the prompts sent to
agents and lets a harness override them. The status view scrolls promptly and
allows ordinary text selection.

**Upgrade notes.** `bb` is deprecated and is still available for one more release with
`TABA_BITBUCKET_TRANSPORT=bb`. Rebuild review bundles made before this release to
post after a GitHub repository rename. For OpenClaw, install the matching CLI and
plugin with `taba openclaw install`, then reload open Control UI tabs. Bitbucket
writes confirmed through an OpenClaw gateway need the separately published
openclaw-bitbucket plugin
[v0.3.7](https://github.com/lcorneliussen/openclaw-bitbucket/releases/tag/v0.3.7);
it is not part of taba's embedded OpenClaw integration.

## Bitbucket

- **TWG is the default Bitbucket client.** Reads and your own writes go through
  `twg`. A host can opt in to per-repository read tokens from its git credential
  helper, which any process on that host can use. Refused reads name the observed
  HTTP status instead of guessing a cause. See `docs/forges.md`
  ([#471](https://github.com/lcorneliussen/taba/issues/471), [#483](https://github.com/lcorneliussen/taba/pull/483), [#513](https://github.com/lcorneliussen/taba/pull/513), [#515](https://github.com/lcorneliussen/taba/pull/515)).

## Review

- **Public reviews run outside the authoring collection**, with a read-only snapshot,
  an allowlisted environment and file-only tools. They now refuse codex and grok.
  Private reviews keep the worktree read-only for claude, and timed-out reviewers
  stop promptly ([#466](https://github.com/lcorneliussen/taba/issues/466), [#479](https://github.com/lcorneliussen/taba/pull/479), [#492](https://github.com/lcorneliussen/taba/pull/492)).
- **Post reviews after a GitHub repository rename** ([#458](https://github.com/lcorneliussen/taba/issues/458), [#464](https://github.com/lcorneliussen/taba/pull/464)).
- **Overlapping review posts create one summary comment** ([#498](https://github.com/lcorneliussen/taba/issues/498), [#507](https://github.com/lcorneliussen/taba/pull/507)).

## Prompts

- **`taba prompts list|show|explain`** shows the prompts taba sends to agents and where
  each comes from. A harness can override one under `harness/prompts/`. See
  `docs/commands.md`. This is phase 1. `taba doctor` repository-reference checks do
  not cover `prompts/` yet ([#448](https://github.com/lcorneliussen/taba/issues/448), [#508](https://github.com/lcorneliussen/taba/pull/508)).

## Services

- **A repository's root `dekit.yaml` declares its services.** A shared add into a
  natively loaded file is refused, and the literal ready URL is shown before
  rendering. See `docs/root-dekit-declarations.md`
  ([#510](https://github.com/lcorneliussen/taba/issues/510), [#514](https://github.com/lcorneliussen/taba/pull/514), [#516](https://github.com/lcorneliussen/taba/pull/516)).
- **`taba doctor` checks named tunnels** locally, without provider access
  ([#450](https://github.com/lcorneliussen/taba/issues/450), [#461](https://github.com/lcorneliussen/taba/pull/461)).
- **A problem in another collection no longer blocks Tailscale tunnels**
  ([#482](https://github.com/lcorneliussen/taba/issues/482), [#505](https://github.com/lcorneliussen/taba/pull/505)).
- **A rejected tunnel host command reports its error instead of panicking**
  ([#485](https://github.com/lcorneliussen/taba/issues/485), [#495](https://github.com/lcorneliussen/taba/pull/495)).

## Upgrades

- **Upgrades and rollouts run the new release's `doctor`.** Its findings are advice
  only ([#450](https://github.com/lcorneliussen/taba/issues/450), [#509](https://github.com/lcorneliussen/taba/pull/509)).

## Runtime

- **A config change that a newer runner would ignore is refused**, with advice to run
  `down` then `up` ([#456](https://github.com/lcorneliussen/taba/issues/456), [#467](https://github.com/lcorneliussen/taba/pull/467)).

## Collections

- **Run the project's CLI from the project root** with `taba env root`. See
  `docs/project-root-version.md` ([#476](https://github.com/lcorneliussen/taba/issues/476), [#480](https://github.com/lcorneliussen/taba/pull/480)).

## Workspace opening

- **An agent start with no confirmed outcome is not sent again.** Inspect the pane,
  then remove `.wtc-agent-start.pending` to allow a new start
  ([#498](https://github.com/lcorneliussen/taba/issues/498), [#507](https://github.com/lcorneliussen/taba/pull/507)).

## Status

- **Text can be selected with an ordinary drag.** The live view no longer captures
  the mouse by default; wheel behaviour depends on the terminal. `v` opens the full
  output on the normal screen for selection and scrollback. `--mouse` keeps the
  in-app wheel and click targets
  ([#473](https://github.com/lcorneliussen/taba/issues/473), [#478](https://github.com/lcorneliussen/taba/pull/478)).
- **Scrolling responds promptly again** ([#481](https://github.com/lcorneliussen/taba/issues/481), [#488](https://github.com/lcorneliussen/taba/pull/488)).
- **Closed and declined PRs are struck through once the closure is confirmed**
  ([#472](https://github.com/lcorneliussen/taba/issues/472), [#474](https://github.com/lcorneliussen/taba/pull/474)).
- **Merged PRs still on their branch keep one readable table line**
  ([#426](https://github.com/lcorneliussen/taba/issues/426), [#469](https://github.com/lcorneliussen/taba/pull/469)).
- **`status --all` reports readable collections when one is unreadable**, then exits
  nonzero ([#459](https://github.com/lcorneliussen/taba/issues/459), [#462](https://github.com/lcorneliussen/taba/pull/462)).
- **A lost cache write no longer lets an older PR state back in**
  ([#493](https://github.com/lcorneliussen/taba/issues/493), [#501](https://github.com/lcorneliussen/taba/pull/501)).

## OpenClaw

- **Restore evicted checkouts as the person who asked**, with named failure causes
  ([#494](https://github.com/lcorneliussen/taba/issues/494), [#499](https://github.com/lcorneliussen/taba/pull/499)).
