# taba/wtc 0.2.7

Inspect configuration requirements without credentials, refresh status explicitly,
and reduce idle status work while preserving observation ages and safety checks.

## Configuration

- **Inspect canonical dotenv requirements.** Doctor, `config list` and explicit
  `secrets list --requirements` share a value-free inventory; default secrets
  listing retains filename/link-state output. `config lint` validates schemas and
  provided owned key names without credentials; process inspection stays explicit.
  ([#263](https://github.com/lcorneliussen/taba/issues/263),
  [#436](https://github.com/lcorneliussen/taba/pull/436)).

## Status

- **Refresh active PR facts with `r`.** Manual Refresh bypasses stale detail/list
  reuse within shared provider allowances and cooldowns, preserving exact-head
  checks and retained merges, with compact freshness and honest retry details.
- **Paint before discovery and reduce idle work.** Startup shows a loading frame;
  saved observations retain validated ages. Unchanged service declarations can be
  reused, with conservative background cadence when focus is unknown. Shared
  cache/budget lock failures defer provider reads, including background and
  one-shot reads. Manual Refresh remains available.
- **Inspect unmerged closures and cancel pending work.** Confirmed closed/declined
  PRs retain archive age/toggle rules, expanded strikethrough and explicit state;
  checked-out branch warnings remain visible. Quit cancels selected discovery,
  provider, hook and admission waits; snapshot publication checks cancellation
  before committing. Committed observations remain
  authoritative; filesystem I/O and arbitrary descendants are not universally
  cancellable.
  ([#424](https://github.com/lcorneliussen/taba/issues/424),
  [#426](https://github.com/lcorneliussen/taba/issues/426),
  [#435](https://github.com/lcorneliussen/taba/pull/435),
  [#438](https://github.com/lcorneliussen/taba/pull/438)).

## Status reload

- **Bound reload observations.** Herdr and pin inspection share a finite budget.
  Unconfirmed interrupt/restart acknowledgements are reported without replay;
  success still requires an observed status process.
  ([#380](https://github.com/lcorneliussen/taba/issues/380),
  [#428](https://github.com/lcorneliussen/taba/pull/428)).

## Release

- **Verify clean binary provenance.** Generated release outputs stay out of source
  status; publication checks each binary against the exact clean Git revision.
  Published 0.2.6 artifacts retain their original metadata.
  ([#433](https://github.com/lcorneliussen/taba/issues/433),
  [#434](https://github.com/lcorneliussen/taba/pull/434)).
- PR CI uses focused native macOS checks; full macOS coverage remains nightly or
  manual. ([#432](https://github.com/lcorneliussen/taba/pull/432)).
