# wtc 0.1.63

This release improves OpenClaw action feedback and publication confirmation,
adds read-only service logs, and clarifies catch-up and reference-only PR status.
The executable and installed plugin identity remain `wtc`.

## Catch-up

- **Unavailable PR state includes lookup context and a next step.** Enlisted
  GitHub and Bitbucket failures identify the repository, PR and operation;
  branch searches identify the branch. Safe cause categories replace raw forge
  output, preserving the existing failure JSON and conflict handoff contracts.
  This addresses only the diagnostics slice of
  [#242](https://github.com/lcorneliussen/wtc-cli/issues/242). See
  [catch-up diagnostics](https://github.com/lcorneliussen/wtc-cli/blob/v0.1.63/docs/catch-up-diagnostics.md).

## OpenClaw

- **Collection panels fill their sidebar host.** Inline-size containment no
  longer shrinks the panel inside a flex layout. Desktop chat-card headers gain
  top space while retaining their bottom inset and shared text baselines.
  ([#269](https://github.com/lcorneliussen/wtc-cli/issues/269)).

- **Service names open recent logs.** A read-only pane below sidebar Services
  shows recent output, including startup failures; the composer card opens it too,
  with Refresh and Close controls. The latest output opens first; status refreshes
  preserve the reading position. Multi-process services offer task buttons.
  Reading logs does not start the service;
  changing conversations clears the pane and discards late responses.
  ([#269](https://github.com/lcorneliussen/wtc-cli/issues/269)).

- **Collection actions keep their feedback in place.** The compact header
  summarizes progress and outcomes, with full details and recent results in the
  sidebar below Services. Selection augments the existing repository rows,
  an aligned All repos row offers bulk push/catch-up, and narrow layouts keep
  action targets and fact positions stable. Shared name/icon rails and compact
  narrow rows reduce near-alignments and empty PR bands. A publication preview
  can open above the collapsed bar while its repository details stay closed.
  Bulk arrows share repository arrow tracks; PR-history links and action-log
  result glyphs keep reserved slots. Text shares a baseline and secondary
  controls follow the host theme. Long branches can be expanded.
  Temporary controls extend above the composer card or below sidebar Services
  while the base slots stay in place.
  The browser card separates collection Services with an outer-margin heading
  and divider. Browser table labels use normal capitalization; terminal headings
  keep their uppercase style.
  ([#269](https://github.com/lcorneliussen/wtc-cli/issues/269)).
- **Publication has a separate confirmation preview.** Preparation shows the
  personal account, repository, branch and captured change count. Confirm push
  and Cancel are distinct controls; repeated taps on preparation cannot publish.
  Preparation and confirmed publication have distinct progress labels.
  Pre-publication status responses are discarded and a fresh status is read
  before the row stops showing work in progress. Uncommitted-only rows offer
  Commit changes instead of an unnumbered push arrow.

## Status

- **Reference-only enlisted PRs resolve from their supported forge URL.** Status
  shows open and merged references without a registry entry or checkout; closed
  references keep their existing omission rule. URL validation refuses unsupported
  hosts, credentials and identity conflicts; lookup does not grant local branch or
  catch-up authority
  ([#279](https://github.com/lcorneliussen/wtc-cli/issues/279)). See
  [enlisted repository identity](https://github.com/lcorneliussen/wtc-cli/blob/v0.1.63/docs/enlisted-repository-identity.md).

## Upgrade

- **Update the matching OpenClaw plugin as well as the CLI.** After replacing
  the gateway host's `wtc` binary with this release, run `wtc openclaw install`
  as the gateway user, then reload open Control UI tabs. The command reinstalls
  the plugin embedded in that binary and reloads it in the running gateway.
  Image-managed gateways should rebuild their image with the matching CLI and
  embedded plugin instead. This release does not migrate the plugin ID or
  configuration keys. See the [OpenClaw upgrade guide](https://github.com/lcorneliussen/wtc-cli/blob/v0.1.63/docs/openclaw.md#upgrade).
