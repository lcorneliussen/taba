# Renamed to taba

Use the **taba** skill and `taba` command when available. This alias remains
for existing conversations and skill allowlists; the procedure lives in taba.

If only this alias is available, read `taba docs instructions/openclaw.md`
and follow those instructions. An older CLI with only the `wtc` binary can
use `wtc docs instructions/openclaw.md` instead. To list projects, use
`taba projects` (`wtc projects` on that older CLI); Taba and wtc name the tool.
